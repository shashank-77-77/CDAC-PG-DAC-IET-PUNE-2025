SESSION 1 – Introduction to DBMS & MySQL

(20 MCQs | Exam-Optimized | Concept + Application Blend)

Q1

A DBMS is best described as:

A. A collection of files
B. A programming language
C. Software that manages databases
D. Hardware used for storage

Answer: C

Q2

Which of the following is NOT a function of DBMS?

A. Data storage
B. Data security
C. Data redundancy increase
D. Data retrieval

Answer: C

Q3

Which component defines how data is physically stored?

A. Schema
B. Instance
C. Metadata
D. Data dictionary

Answer: A

Q4

A database instance refers to:

A. Database structure
B. Database design
C. Database content at a particular time
D. Database constraints

Answer: C

Q5

Which term refers to “data about data”?

A. Instance
B. Schema
C. Metadata
D. Record

Answer: C

Q6

Which DBMS type stores data in tables with rows and columns?

A. Hierarchical
B. Network
C. Relational
D. Object-oriented

Answer: C

Q7

Which DBMS allows flexible schema and horizontal scaling?

A. Relational
B. Object-relational
C. File-based
D. NoSQL

Answer: D

Q8

Which of the following is a NoSQL database?

A. MySQL
B. Oracle
C. PostgreSQL
D. MongoDB

Answer: D

Q9

Which DBMS type combines relational model with object concepts?

A. Network DBMS
B. Hierarchical DBMS
C. Object-relational DBMS
D. Distributed DBMS

Answer: C

Q10

Which of the following is NOT a MySQL client?

A. MySQL Monitor
B. MySQL Shell
C. MySQL Workbench
D. MySQL Server

Answer: D

Q11

MySQL Workbench is primarily used for:

A. Command-line execution only
B. GUI-based database design and administration
C. OS-level file management
D. Backup automation only

Answer: B

Q12

Which MySQL client supports scripting and multiple APIs?

A. MySQL Monitor
B. MySQL Shell
C. MySQL Workbench
D. phpMyAdmin

Answer: B

Q13

Which layer ensures data abstraction in DBMS?

A. Physical layer
B. Application layer
C. Logical layer
D. All of the above

Answer: D

Q14

Which advantage of DBMS reduces data duplication?

A. Data security
B. Data independence
C. Data redundancy control
D. Data abstraction

Answer: C

Q15

Which user interacts directly with the database using queries?

A. End user
B. Database administrator
C. Application programmer
D. System analyst

Answer: A

Q16

Which role is responsible for database security and backup?

A. End user
B. DBA
C. Developer
D. Tester

Answer: B

Q17

Which DBMS feature allows multiple users to access data simultaneously?

A. Integrity
B. Concurrency control
C. Normalization
D. Indexing

Answer: B

Q18

Which concept allows applications to remain unaffected by database changes?

A. Data redundancy
B. Data consistency
C. Data independence
D. Data concurrency

Answer: C

Q19

Which of the following is a disadvantage of file-based systems?

A. Easy recovery
B. Low redundancy
C. Poor data sharing
D. Strong security

Answer: C

Q20

DBMS primarily evolved to overcome limitations of:

A. Operating systems
B. File processing systems
C. Programming languages
D. Computer networks

Answer: B

SESSION 2 – Data Models, ERD, Codd’s Rules & SQL Basics

(20 MCQs | CCEE-Weighted | High Signal, Low Noise)

Q1

Which data model focuses on business entities and relationships?

A. Physical
B. Logical
C. Conceptual
D. Internal

Answer: C

Q2

Logical data model primarily represents:

A. Storage structures
B. Tables, keys, and relationships
C. Disk allocation
D. File organization

Answer: B

Q3

Which data model is closest to actual database implementation?

A. Conceptual
B. Logical
C. Physical
D. External

Answer: C

Q4

An ER diagram is mainly used during:

A. Database tuning
B. Database design
C. Query optimization
D. Backup planning

Answer: B

Q5

In an ER diagram, an entity is represented by:

A. Ellipse
B. Diamond
C. Rectangle
D. Line

Answer: C

Q6

Which ER component represents an attribute?

A. Rectangle
B. Diamond
C. Ellipse
D. Double line

Answer: C

Q7

A weak entity is identified by:

A. Primary key only
B. Foreign key only
C. Partial key and owner entity
D. Unique constraint

Answer: C

Q8

Which relationship cardinality means “one-to-many”?

A. 1:1
B. M:N
C. 1:N
D. N:1

Answer: C

Q9

Codd’s rules define:

A. SQL syntax
B. File system constraints
C. Characteristics of relational databases
D. NoSQL principles

Answer: C

Q10

Which Codd rule enforces data access only through relational operations?

A. Rule of Integrity
B. Rule of Guaranteed Access
C. Rule of Data Independence
D. Rule of Non-subversion

Answer: B

Q11

SQL stands for:

A. Structured Query Language
B. Simple Query Language
C. Standard Query Language
D. Sequential Query Language

Answer: A

Q12

Which SQL category defines database structure?

A. DML
B. DCL
C. DDL
D. TCL

Answer: C

Q13

Which command is used to permanently remove a table?

A. DELETE
B. DROP
C. TRUNCATE
D. REMOVE

Answer: B

Q14

TRUNCATE differs from DELETE because it:

A. Can be rolled back
B. Removes table structure
C. Is faster and non-transactional
D. Removes specific rows only

Answer: C

Q15

Which SQL command modifies table structure?

A. UPDATE
B. ALTER
C. INSERT
D. SELECT

Answer: B

Q16

Which SQL command removes all rows but keeps table structure?

A. DELETE
B. DROP
C. REMOVE
D. TRUNCATE

Answer: D

Q17

Which SQL category controls user permissions?

A. DDL
B. DML
C. DCL
D. TCL

Answer: C

Q18

COMMIT and ROLLBACK belong to:

A. DDL
B. DML
C. DCL
D. TCL

Answer: D

Q19

Which SQL command is used to add a new column?

A. ADD
B. MODIFY
C. ALTER TABLE
D. CREATE COLUMN

Answer: C

Q20

Which statement about DDL is correct?

A. DDL commands can be rolled back
B. DDL affects data only
C. DDL changes database schema
D. DDL is part of DML

Answer: C
