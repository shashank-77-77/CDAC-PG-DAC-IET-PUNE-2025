Scope: Full syllabus coverage

EASY LEVEL (1–20)

An Operating System is best defined as
A) A hardware component
B) A system software that manages hardware and software resources
C) An application software
D) A programming language
Ans: B

The primary purpose of an Operating System is to
A) Execute user programs
B) Manage hardware resources
C) Provide user interface
D) All of the above
Ans: D

Which of the following is NOT a function of an Operating System?
A) Memory management
B) Process management
C) File management
D) Code compilation
Ans: D

OS acts as an interface between
A) User and application
B) Hardware and application
C) User and hardware
D) Compiler and linker
Ans: C

Which of the following is system software?
A) MS Word
B) Web browser
C) Linux
D) Media Player
Ans: C

The core component of an Operating System is called
A) Shell
B) Kernel
C) Loader
D) File system
Ans: B

Kernel operates in
A) User mode
B) Application mode
C) Privileged mode
D) Guest mode
Ans: C

User programs execute in
A) Kernel mode
B) Supervisor mode
C) User mode
D) Hypervisor mode
Ans: C

Which OS is designed to meet strict timing constraints?
A) Desktop OS
B) Batch OS
C) Real-Time OS
D) Network OS
Ans: C

Android OS is an example of
A) Embedded OS
B) Desktop OS
C) Mobile OS
D) Server OS
Ans: C

Embedded Operating Systems are mainly used in
A) Supercomputers
B) Personal computers
C) Dedicated hardware devices
D) Mainframes
Ans: C

The OS component that interacts directly with hardware is
A) Shell
B) Compiler
C) Kernel
D) Application
Ans: C

Which of the following manages CPU scheduling?
A) File system
B) Process manager
C) Memory manager
D) I/O manager
Ans: B

Interrupts are used to
A) Stop CPU permanently
B) Signal CPU for immediate attention
C) Increase clock speed
D) Allocate memory
Ans: B

Which mode has more privileges?
A) User mode
B) Kernel mode
C) Both equal
D) Depends on OS
Ans: B

Which OS is typically used on servers?
A) RTOS
B) Desktop OS
C) Server OS
D) Embedded OS
Ans: C

System calls are used to
A) Compile programs
B) Access kernel services
C) Edit files
D) Boot OS
Ans: B

Which of the following is an example of desktop OS?
A) Windows
B) VxWorks
C) FreeRTOS
D) RTLinux
Ans: A

Hardware dependency of OS means
A) OS cannot run programs
B) OS is tied to specific hardware architecture
C) OS depends on user
D) OS depends on application
Ans: B

Booting is the process of
A) Loading OS into memory
B) Shutting down OS
C) Installing OS
D) Updating OS
Ans: A
